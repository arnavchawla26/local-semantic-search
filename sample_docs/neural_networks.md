# Notes on Neural Networks

Backpropagation is the algorithm used to train neural networks by computing
the gradient of the loss function with respect to each weight, propagating
the error backward through the layers using the chain rule. Gradient
descent then uses these gradients to update the weights.

Key concepts: activation functions (ReLU, sigmoid, tanh), the vanishing
gradient problem in deep networks, and how batch normalization helps
stabilize training.
