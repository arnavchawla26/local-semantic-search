# Notes on Databases

A database index is a data structure (commonly a B-tree or hash table)
that improves the speed of data retrieval operations at the cost of extra
writes and storage. Composite indexes cover multiple columns and are
useful when queries filter or sort on more than one field together.

Normalization reduces data redundancy by organizing fields and tables
according to rules (1NF, 2NF, 3NF), while denormalization trades some
redundancy for read performance.
